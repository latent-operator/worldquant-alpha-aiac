# AIAC goal evidence and handoff

## Why

AgentsView sessions and Git history show repeated local improvements without a WQ quality PASS. The objective needs a durable acceptance contract and a task graph that survive context compaction.

## What Changes

- Define one stable research goal and its evidence levels in OpenSpec.
- Use Beads for the outstanding safety, candidate and verification tasks.
- Add a deterministic read-only evidence gate for experiment reports.
- Use RD-Agent's hypothesis–experiment–feedback loop as a design reference without installing its Qlib runtime.

## Impact

Local developer tooling and offline eval only. No WQ POST, Alpha submission, production task control or AIAC release is part of this change.
